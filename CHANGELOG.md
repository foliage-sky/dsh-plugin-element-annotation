# Changelog

## 0.1.0

- Initial release.
- Annotate button in the document preview header.
- Element picking with blue dashed outline; drag to select a region.
- One-line change-request composer with Enter / ✓ confirm; Esc cancels.
- Re-target by dragging elsewhere; clicking empty space exits.
- Floating annotation panel with per-item delete, clear, and batch submit to the composer.
